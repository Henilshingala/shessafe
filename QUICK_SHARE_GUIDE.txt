INSTALLATION INSTRUCTIONS FOR USERS
================================================================================

FIRST TIME INSTALLATION:
1. Download APK from WhatsApp
2. Open file manager (Files app)
3. Navigate to Downloads folder
4. Find "app-release.apk"
5. Tap it to open
6. If prompted "Unknown app from unknown source" - tap "Install anyway"
7. Wait for installation to complete
8. Tap "Open" or find app in home screen

PERMISSIONS:
- App will show 3-step onboarding
- Step 1: Welcome screen
- Step 2: Permissions information
- Step 3: Enter your phone number and IoT SIM number
- Tap "Continue" to request permissions
- Grant all permissions (SMS, Notifications, Call)
- App opens to home screen

TROUBLESHOOTING:
- If "Unknown source" error: Enable "Unknown sources" in Settings > Security
- If "App not installed": Free up device storage (need ~50MB free)
- If app crashes: Restart device and reinstall
- If permissions denied: Uninstall and reinstall, grant all permissions
